# 被动信息收集


## 1. 什么是被动信息收集

被动信息收集（Passive Reconnaissance）是信息收集的重要阶段。

它指在不直接与目标系统进行交互的情况下，通过公开渠道获取目标相关信息。

被动信息收集主要依靠互联网公开信息，包括：

- 企业公开信息
- 域名信息
- DNS信息
- 搜索引擎信息
- 历史资产信息


通过被动信息收集，可以在较低风险的情况下了解目标组织的互联网暴露情况。


## 2. 为什么需要被动信息收集

在进行主动探测之前，需要先了解目标的基本情况。

如果直接进行扫描，可能会：

- 不清楚目标范围
- 扫描大量无关资产
- 遗漏重要入口
- 无法判断资产归属


被动信息收集可以帮助我们：

- 确认目标组织信息
- 发现目标相关域名
- 了解目标可能存在的资产
- 为后续主动信息收集提供方向


## 3. 被动信息收集的信息来源


### 3.1 企业公开信息

企业或组织的公开信息可以帮助确认目标身份以及相关资产。

主要关注：

- 企业名称
- 组织关系
- 官方网站
- 业务范围
- 公开联系方式


目的：

通过组织信息确定目标主体，为后续资产发现提供依据。


### 3.2 域名信息

域名是互联网资产的重要入口。

通过域名信息，可以了解：

- 主域名
- 域名注册信息
- 域名关联关系
- 可能存在的子域名


目的：

发现目标可能存在的互联网入口。


### 3.3 DNS信息

DNS负责将域名解析到对应的网络资源。

通过DNS信息，可以了解：

- 域名对应IP地址
- DNS服务器信息
- 域名解析关系


目的：

建立域名与服务器之间的关联。


### 3.4 搜索引擎信息

搜索引擎保存了大量互联网公开信息。

通过搜索引擎可以发现：

- 网站页面
- 公开文档
- 暴露的信息
- 历史页面


目的：

发现目标公开暴露的信息。


### 3.5 历史资产信息

互联网资产可能会发生变化。

一些已经下线或者变化的资产，可能仍然存在历史记录。

关注：

- 历史域名
- 历史解析记录
- 历史网站信息


目的：

发现当前资产之外的关联信息。


## 4. 被动信息收集流程

```
目标组织
↓
收集组织公开信息
↓
确定目标域名
↓
分析域名相关信息
↓
获取DNS及历史信息
↓
整理可能存在的资产
```




## 5. 被动信息收集与主动信息收集的区别


### 被动信息收集

特点：

- 不直接访问目标系统
- 主要依靠公开数据
- 风险较低


获取的信息：

- 域名
- 企业信息
- DNS记录
- 历史信息


### 主动信息收集

特点：

- 直接与目标系统交互
- 需要发送探测请求
- 更容易获得详细信息


获取的信息：

- 开放端口
- 服务信息
- Web指纹


## 6. 总结

被动信息收集是信息收集流程中的基础阶段。

通过公开信息，可以提前了解目标组织和互联网资产情况，为后续主动信息收集提供方向。

一个完整的信息收集流程应该先进行被动信息收集，再根据已有信息开展主动探测。
