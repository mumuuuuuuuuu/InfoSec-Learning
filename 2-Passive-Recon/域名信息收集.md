# 域名信息收集


## 1. 为什么需要域名信息收集

在企业信息收集阶段，我们通常可以通过企业公开信息获取官方网站。

例如：

```
目标组织
↓
官方网站
↓
xxx.com
```


但是，一个组织的互联网资产通常不止一个主域名。

除了官方网站之外，还可能存在：

- 子域名
- 业务系统域名
- 邮件系统域名
- 管理后台域名


因此，需要进一步对域名进行分析，发现更多可能存在的互联网资产。


## 2. 域名信息收集目标


域名信息收集主要关注：

### 2.1 域名注册信息

包括：

- 域名注册商
- 注册时间
- 到期时间
- DNS服务器


作用：

了解域名基本情况。


### 2.2 DNS信息

包括：

- 域名解析记录
- DNS服务器
- IP地址


作用：

建立域名和服务器之间的关系。


### 2.3 关联域名发现

通过公开信息发现：

- 子域名
- 历史域名
- 关联域名


作用：

扩大目标资产范围。


# 3. Whois域名查询


## 3.1 工具介绍


Whois是一种用于查询域名注册信息的协议。


通过Whois查询，可以获取域名公开注册信息。


常见查询网站：

站长工具：https://whois.chinaz.com

## 3.2 Whois获取的信息


主要包括：

- 域名名称
- 注册商
- 注册时间
- 到期时间
- DNS服务器


## 3.3 Whois工具原理


Whois查询通过访问域名注册机构公开数据库，获取域名注册相关信息。


由于域名注册信息具有公开性，因此可以作为信息收集的重要来源。


## 3.4 Whois信息分析


获取到的信息可以帮助：

- 判断域名注册时间
- 分析域名归属
- 获取DNS服务器信息

# 4. 域名信息收集流程


```
获取目标域名
↓
Whois查询
↓
了解域名基础信息
↓
SSL证书查询
↓
发现关联域名
↓
整理资产信息
```

# 5. 注意事项


- Whois信息可能受到隐私保护影响。

- 发现的域名不一定全部属于目标范围，需要结合实际情况判断。


# 6. 总结


域名信息收集是被动信息收集的重要环节。

通过Whois等公开信息，可以进一步了解目标域名情况，并发现更多潜在资产。
