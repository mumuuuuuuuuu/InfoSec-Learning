# 信息收集学习笔记



## 学习目标

系统学习网络安全中的信息收集流程。

掌握从目标范围确定，到资产发现，再到信息整理输出的完整过程。

学习过程中结合实际工具，理解工具使用方法以及背后的工作原理。

最终能够独立完成目标资产的信息收集，并形成结构化资产列表。



## 信息收集流程

### 1.资产范围界定

目标：

明确需要收集的目标范围，确定信息收集方向。

学习内容：

- 明确目标组织
- 确定目标域名
- 确定资产边界
- 分析目标可能存在的资产类型


### 2.被动信息收集

目标：

通过公开信息发现目标相关资产。

学习内容：

- 企业公开信息
- 域名信息
- DNS信息
- 搜索引擎信息
- 历史资产信息


### 3.主动信息收集

目标：

通过主动探测发现目标暴露资产。

学习内容：

- 子域名发现
- IP发现
- 端口扫描
- 服务识别


### 4.Web资产分析

目标：

深入分析Web资产技术信息。

学习内容：

- 网站状态
- Web服务器
- 技术栈
- CMS识别
- 中间件识别


### 5.信息整理输出

目标：

将收集的信息整理成可分析的资产表。

输出内容：

- 域名
- IP
- 端口
- 服务
- 网站标题
- 技术信息
- 风险信息
